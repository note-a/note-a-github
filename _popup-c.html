개요 OVERVIEW

공간 구조 사진에 적용하는 지시문 변환 규칙입니다. 각 문법(Grammar)에서 도출된 DIR 코드를 기반으로 실제 촬영 지시문을 생성합니다.

적용 대상 문법

  • DIR-01 HRZLAY — 수평 레이어: 인공 구조물이 자연을 수평 분리
  • DIR-04 VANSRC — 소실점 수렴: 선형 구조가 발광 지점으로 수렴
  • DIR-07 EQREP — 등간격 반복: 동일 형태의 규칙적 배열

변환 기준 CONVERSION

아래 기준표에 따라 각 문법 코드를 지시문으로 변환합니다. 1차 문법(G-01~G-10)은 필수 적용, 2차 문법은 선택 적용.

핵심 원칙: 지시문은 "무엇을 찍을 것인가"가 아니라 "어떤 시각 구조를 만들 것인가"에 집중한다. 결과물의 구조적 속성을 명시할 것.
