## 1. 개요

2026.03.16 촬영분 DSCF6367~6749, 총 354장 대상. 2차 신규 DIR 14개 전체 적용, 사진 평가 기준표 v5.0 기준. Core 2장, Support 6장 선별. 비고 26건, 보류 1건.

---

## 2. 촬영 구역 및 씬 구성

크게 4개 구역으로 분류된다.

**A구역 — 강변 산책로 (6367~6465)**  
한강 지류 강변 호안 블록, 교각, 나무들, 버드나무 군락. MATCOV Support 1(6375 흙더미 피복), LGTPAT Support 1(6378 언더패스 그림자 패턴)이 이 구역의 성과 전부. OVERGROW 비고 6건(6392/6437/6453/6458/6460/6490)이 집중 발생했으며 나무 뿌리·담쟁이덩굴의 호안 블록·기둥 점거 씬이 반복. 버드나무 씬 12장 이상이 동일 씬 계열로 전원 Drop.

**B구역 — 도시 이면도로 (6466~6554)**  
가로등, CCTV, 빈 게시판, 태양광 패널, 온실 외벽. REPDOM Core 1(6491 성동구 공사 가림막)이 이 구역 유일한 Core. 빈 게시판·철망·태양광 패널 반복 씬(6536~6554)이 약 20장 동일 씬 계열로 연속 발생, 전원 Drop. MIRRORSURF 비고 2건(6459/6486), VANISH 비고 2건(6497/6500).

**C구역 — 서울식물원 온실 내부 (6555~6675)**  
열대·아열대 식물원 내부. 약 120장. 온실 내부 식물들은 "자연스럽게 존재하는 경우" 기각 조건이 반복 적용되어 전 씬 Drop 또는 비고 처리. OVERGROW 비고 2건(6556/6559)은 유리 케이스 외벽·흰 회벽에 담쟁이가 피복한 씬으로 외부 구조물 점거에 해당. GLASSDUAL 비고 1건(6595 어항+인물 반사), VANISH 비고 1건(6586 산책로 소실점). 온실 내부 씬 자체에서 2차 신규 DIR이 한 건도 작동하지 않은 구역.

**D구역 — 공원 외부·건물 주변 (6676~6749)**  
서울식물원 외부 공원, 나무숲, 초록 외벽 창고, 공사 현장, 카페 내부. 이번 촬영 후반부 핵심 성과 구역. EQREP Core 1(6699 공원 나무 기둥 등간격 배열) + EQREP Support 2(6707 초록 패널 반복 / 6748 카페 줄무늬 벽) + EQREP Support 1(6717 계단 구조물 수직 반복) + MATCOV Support 1(6745 파란 방진망 피복) 발생. OVERGROW 비고 1건(6676 담쟁이+담장 전체 피복).

## 3. DIR별 선별 분석

**EQREP** — 1 Core, 3 Support  
이번 촬영 최다 성과 DIR. D구역에 집중 발생. 6699(공원 나무 기둥)는 인위적 등간격 배열이 명확한 씬으로 Core 확정. 6707(초록 패널)·6717(계단 수직 반복)·6748(줄무늬 벽)는 전경 나무 또는 의자가 간섭하여 Support. EQREP 4장 집중 발생은 클리셰 우려 구간이나, 각각 자연·건축·실내 서로 다른 맥락에서 발생하므로 현재 단계에서 문제 없음.

**REPDOM** — 1 Core  
6491 단독. 성동구 로고 흰색 공사 가림막이 화면 70% 점유, 인물이 1/8 이하 크기로 배치된 씬. 인물배경 카테고리 2차 DIR 중 이번 촬영에서 유일하게 작동한 케이스.

**MATCOV** — 0 Core, 2 Support  
6375(흙더미 피복)와 6745(파란 방진망 피복). 두 씬 모두 단일 소재의 균질 피복이 명확하나 경쟁 요소로 Support 처리. 0304 촬영 대비 Core 0건은 피복 면적 충족 씬이 적었기 때문.

**LGTPAT** — 0 Core, 1 Support  
6378(언더패스 바닥 그림자 패턴)만 발생. 0304 촬영(4 Core, 3 Support)과 비교하면 LGTPAT 씬이 현저히 줄었다. 그림자 패턴을 생성하는 투과성 구조물(펜스·격자) 앞에서 일조 조건이 충분한 씬 자체가 적었던 것이 원인.

## 4. 비고 항목 분석 (26건)

**OVERGROW (10건)**: 6392·6437·6453·6458·6460·6490·6527·6556·6559·6676. 강변 호안 블록+나무 뿌리 계열(6건)이 가장 집중적으로 발생. 구조물 표면을 식물이 물리적으로 점거하는 패턴이 이 날 촬영의 지배적 씬 유형이었음. 2차 전환 가능성은 있으나 현재 ARTNAT·MATCOV 조건과의 중복 검토 필요.

**VANISH (4건)**: 6497·6500·6586·6693. 산책로·계단·호스 두 줄이 소실점으로 수렴하는 씬. 1차 DIR 작동으로 비고 처리.

**PEEL (3건)**: 6424·6521·6522. 뜯긴 스티커, 콘크리트 박리 씬. 이전 촬영과 동일 유형 반복.

**MIRRORSURF (2건)**: 6459·6486. 물웅덩이 반사, 건물 유리 반사. 1차 DIR.

**EQREP (3건)**: 6368·6507·6508. 삼각형 패턴, 가로수, 과수원 나무 등간격. 1차 비고로 처리했으나 EQREP는 2차 신규 DIR임을 확인 — 재검토 시 Core/Support 승격 가능성 있음 (간섭 조건 재분석 필요).

**GLASSDUAL (2건)**: 6546·6595. 온실 유리+식물+반사 중첩 씬. 1차 DIR.

**OVERGROW·기타**: 이번 촬영에서 FOGDIS·ISOOBJ·ARTNAT는 단 한 건도 발생하지 않음. UNIDIST는 6534 보류 1건.

## 5. 특이사항

- **온실 구역 생산성 저하**: 120장 중 비고 4건, 나머지 전원 Drop. 의도된 탐색이었다면 자연스럽게 존재 기각을 우회할 구도 전략 필요.
- **비고 EQREP 재검토**: 6368(삼각형 패턴)·6507(가로수 배열)·6508(과수원 배열)이 1차 비고로 처리됐으나 EQREP는 2차 신규 DIR. 배경 간섭 재검토 후 승격 여부 판단 요청.
- **보류 1건**: DSCF6534(UNIDIST) — 마른 풀+붉은 줄기 혼재 씬. UNIDIST 비균등 분포 조건 충족 여부 판단 요청.
- **EQREP 클리셰 경보**: D구역에서 4건 집중. 당장 문제는 아니나 다음 촬영에서 동일 DIR 과잉 시 재검토.
