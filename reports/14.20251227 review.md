## 촬영 경향 분석

**CLUSTER·OVERGROW 양분 구조**: 이번 배치 통과컷 28장 중 13장(46%)이 이 두 DIR에 집중. CLUSTER는 전기 계량기·교량 볼트·통신 철탑 장비 등 인공물 밀집 구조에서, OVERGROW는 마른 덩굴이 가로등·안내판·격자 구조물을 점령하는 장면에서 반복 작동.

**OVERGROW Core 0**: Support 6장 전체가 배경 도시 요소(건물·하늘·도로·교량)와 경쟁하며 Core 전환에 실패. 덩굴이 인공 구조물을 점령하는 조건은 충족하나, 배경 차단이 이번 배치 내내 미달. 수직 구조물(기둥·전봇대)을 단독으로 클로즈업할 수 있는 촬영 각도 확보가 선행 과제.

**CLUSTER Core 전환 조건 확인**: DSCF3271(통신 철탑 하단 클로즈업)이 3272·3273 대비 Core 획득. 동일 피사체에서 배경 노출 최소화 여부가 판정을 가름. 거리와 화각 선택이 CLUSTER Core 획득의 핵심 변수로 확인됨.

**겨울 마른 식물 씬 대거 낙제**: DSCF3147–3210 구간 60여 장이 마른 풀·낙엽·덩굴을 주 피사체로 촬영했으나 전수 Drop. 식물 자체가 말라 피사체 강도가 낮고, 배경이 억새밭·도로로 경쟁하는 구조가 반복됨. OVERGROW·FLOAT 등 DIR 작동이 아닌 풍경 촬영에 가까운 접근.

**Support 강등 주 원인**: 배경 잔존(건물·도로·하늘) 80% / 동일 씬 중복 구도 약화 12% / DIR 조건 부분 충족(WRAP 상단 노출 등) 8%.

**v4.0 → v4.1: Core 기준의 전환**

가장 큰 변화는 Core 판정 기준이 바뀐 거야. v4.0에서는 DIR 2개 이상 작동이면 Core 자격이었는데, v4.1에서는 DIR 개수 기준을 폐기하고 확정도(확정/경계)로 전환했어. DIR 하나라도 의심 없이 확정되면 Core 자격, 걸치거나 약하게 읽히면 Support 자격. "두 개가 걸치는 것보다 하나가 확정되는 게 낫다"는 원칙.

두 번째는 0-B에 피사체 유형 트리아지 추가. 인물이 있으면 인물 DIR만, 공간이면 공간 DIR만 점검하도록 범위를 좁혔어. v4.0에서는 40개 전체를 순서대로 훑는 구조였고.

---

**v4.1 → v5.0: 평가 구조 자체의 재설계**

이건 수정이 아니라 거의 재작성 수준이야.

v4.1까지는 0-A → 0-B → 1단계(확정도) → 2단계(작가 잔재) → 3단계(외부 시선)의 순차 강등 구조였는데, v5.0은 층0(판독 가능성) → 층1(지시문 작동 여부) → 층2(간섭 진단)의 3층 구조로 바꿨어.

핵심적인 개념 변화가 두 가지야.

첫째, 배경의 지위. v4.x에서 배경 간섭은 Core 탈락의 직접 원인이었는데, v5.0에서는 "배경이 있다 ≠ 간섭이다"로 명시됐어. 배경이 DIR 독해를 방해하지 않으면 간섭이 아닌 거고, 간섭의 강도가 DIR 작동보다 클 때만 판정에 영향을 줘.

둘째, 작가 잔재 검사와 외부 시선 검사가 별도 단계로 존재하다가 v5.0에서 층2의 간섭 유형(의도 간섭, 서사 간섭)으로 통합됐어. 단계별 강등 메커니즘이 없어지고, 강도 비중으로 판단하는 구조로.

DIR 조건 차원에서는 OVERGROW에서 "나무 수간 경유 제외" 조건이 삭제됐어. 지시문 원문을 대조했더니 그 조건이 지시문에 없는, 경험적으로 추가된 것이었다고 명시돼 있어. GLASSDUAL의 야간 조도 필수 조건도 완화됐고.

---

전체 흐름으로 보면 v4.x는 "조건 충족 여부를 체크리스트로 확인하는" 구조였고, v5.0은 "지시문 작동이라는 단일 질문 아래 간섭 강도를 판단하는" 구조로 이동한 거야. 판정 기준의 출처를 지시문 원문으로 명확히 제한한 것도 v5.0의 특징이고.
